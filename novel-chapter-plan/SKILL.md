# 章节细纲、钩子与包装

## 一、标准细纲模板

每章细纲用以下结构（`novel_chapter_plan` 类任务按此组织；细纲定稿后由你亲自按其成文）：

```
第 N 章细纲：《章节标题》
- 本章目标：这一章在主线上推进什么（一句话）
- 承接：上一章结尾的场景/情绪，本章如何接
- 事件序列：3–6 拍，每拍一句话（谁做了什么、结果如何）
- 转折点：本章最关键的一拍（位置约在章节 60–75% 处）
- 爽点：类型 + 压转爽的分布
- 伏笔操作：铺设哪条 / 发酵哪条 / 回收哪条（对应伏笔清单编号或名称）
- 出场人物：名单 + 每人本章的状态与动机要点
- 结尾钩子：类型 + 具体内容
- 预计字数：
```

**本章监控表**（细纲附表，成稿后逐项对照验收）：

```
| 拍 | 情绪 | 爽点/钩 | 伏笔 | 验收 |
|----|------|--------|------|------|
| 1  | 压（低） | —     | 发酵#3 | ☐ |
| 2  | 升      | 微爽   | —     | ☐ |
| 3  | 峰      | 主爽点 | —     | ☐ |
| 4  | 落+钩   | 钩子   | 铺设#7 | ☐ |
```

情绪列填曲线走向（压/升/峰/落），爽点列标类型与位置，验收列成稿后勾选——任何一拍“写了但没落实”就是本章欠账，下一章必须补。

## 二、钩子类型库（章末留钩）

八种章尾钩，在情绪/动作的**前一秒**断章（绝不在情绪最高点写完）：
1. 悬念钩：新信息抛出一半（信物来历、幕后黑手的一角）。
2. 危机钩：危险逼近但本章不解（敌人在路上、倒计时开始）。
3. 期待钩：明确的下一章看点（明天就是比武、即将见面）。
4. 情绪钩：情绪余韵（和解未说出口、误会刚埋下）。
5. 反转钩：最后一句话推翻本章认知。
6. 打脸预告钩：下一章即将碾压（配合打脸四拍的“沉默”拍断章）。
7. 关系钩：人物关系即将变化（摊牌、重逢、背叛前夜）。
8. 信息钩：关键信息即将揭晓（信封拆开前一秒）。

钩子靠事件与具体信息，不靠感叹与抒情；埋的钩 1–3 章内必兑现，大钩套小钩（卷级主悬念下挂章级小悬念）。

## 三、七种开篇结构

新书/新卷开篇从其中选 2–3 种各写一版再定：悬置危机 / 身份反差 / 结局倒挂 / 替身挡刀 / 金手指激活 / 日常爆破 / 反派开局。每版给：3 句以内的开篇文字 + 钩点解析（读者为什么必须往下看）+ 承接建议（怎么接黄金三章，法则见《novel-plotting》）。

## 四、章节规划（任务流程）

把剧情弧线拆解为逐章计划：每章按标准细纲模板填全字段，附本章监控表；伏笔操作对照工程的 `伏笔清单.md`（工程约定见《novel-project》）。

## 五、书名与简介包装（任务流程）

书名——题材关键词 + 爽点暗示 + 检索友好；给 5-8 个候选分组（直白型/悬念型/反差型），各配思路。简介——前两行抛冲突与金手指，中段给爽点预期，结尾留钩；150-300 字；注意平台风格差异。前情提要（200 字内，只讲读后文必需的信息）与章末摘要（100 字内，本章事件与钩子）同此节。
