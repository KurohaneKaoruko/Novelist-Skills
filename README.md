# Novelist-Skills

通用小说方法论 skill 集合。

## 内容

**12 个方法论 skill**

| skill | 职责 |
| --- | --- |
| `novel-project` | 工程初始化与项目结构 |
| `novel-profiles` | 人物卡 / 设定集 / 世界观 / 文风卡建档 |
| `novel-craft` | 写作工艺总纲 |
| `novel-plotting` | 情节构思与节奏 |
| `novel-chapter-plan` | 章节细纲、钩子与书名简介包装 |
| `novel-prose-standards` | 行文标准（正文铁律） |
| `novel-human-touch` | 人味与情绪外化 |
| `novel-revision` | 改稿工序（润色/改写/翻译/去 AI 味） |
| `novel-ai-lexicon` | 去 AI 味词级特征库 |
| `novel-ai-structure` | 去 AI 味句式与结构层特征库 |
| `novel-continuity` | 连续性 / 设定一致性 |
| `novel-analysis` | 成稿分析 |

> **字节预算**：每个 `SKILL.md` 渲染为 skill 工具结果时须保持在 8192 字符以下
> （超出会被标准预设的 tool-result pruner 裁剪）。新增内容时注意控制体积，
> 单文件超限就把独立职责拆成新 skill，并用《skill 名》互链。

**6 个文风 skill（`novel-style-*`，按作品归属加载）**

`hotblood`（热血）· `lightnovel`（轻小说）· `mystery`（推理）· `romance`（言情）· `scifi`（科幻）· `xianxia`（仙侠）
